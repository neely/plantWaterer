# plantWaterer

A small personal web app that tells me when each of my plants needs water.

**Live:** not deployed yet.

## What it is
plantWaterer keeps a list of my plants. Each plant has its own watering
schedule (for example, every 7 days) and the date it was last watered. The app
shows which plants are due today. A daily email lists the plants to water.

It is for one person: me. It is not a plant-identification tool or a
plant-care guide.

Status: planning only. No application code exists yet. See PLAN.md.
